Requesting a return

Returns are available only for fabric. Please submit your return request within 10 days of receiving your order and include your order reference and the fabric items you wish to return. Stitched items are not eligible for return. Keep the packaging and proof of purchase, and wait for return instructions before sending anything back.

Eligible fabric and excluded items

Fabric must be unused, unwashed and unaltered, with its original tags and packaging. No returns are offered on stitched items, including ready-made garments, custom-stitched garments and fabric supplied with stitching. If your order contains both fabric and stitched items, only the eligible fabric items can be requested for return within the 10-day window.

Review, shipping and refunds

We will review your request and confirm the return address, any shipping costs, and whether a return, exchange, repair or refund is appropriate. Refund amounts, method and expected processing time will be confirmed with you before the return is arranged. A request is not an automatic approval. These instructions do not remove any rights available under applicable law.

Cancellations and alterations

Contact us promptly if you need to cancel or change measurements. Available options depend on whether fabric has been cut, stitching has started or the parcel has been dispatched.

Request a fabric return

For fabric only, within 10 days of delivery. Stitched items cannot be returned under this policy.

Submitting a request does not approve a return or issue a refund.
